# 账号与升级衔接（v1.36.1）

应用直接打开首页。AI 作文与快问 AI 保留直接使用的入口。搜题按服务端实际返回处理：
解密后的正文是个人中心登录提醒时，单题、整页和框选结果都显示“前往登录”按钮，
用户主动登录成功后继续原题。取消登录保留结果页和原图，不循环拉起登录页。

本版删除搜题设备保护 SDK、JNI 包装、包名/签名元数据适配、票据等待和相关网络探针。
答案解密继续使用现有协议的 Java/Kotlin 密钥派生；版本常量和签名材料缓存格式保持一致。

## 保留旧版登录数据

- 应用 ID 仍为 `com.heikeji.phonesearch`，版本号为 `1.36.1`，versionCode 为 `41`。
- 安装包沿用既有签名链，覆盖安装即可升级。
- 账号偏好文件仍为 `secure_account`，键仍为 `iv` 与 `ciphertext`。
- Keystore alias 仍为 `watch_search_session_v1`；AES/GCM/NoPadding、256 位密钥与
  Base64 格式均保持一致。Android 5.0/5.1 的软件密钥派生材料也保持一致。
- JSON 字段仍为 `kduss/name/uid/grade/identityIdV2/occupationType`。
- 启动只恢复已保存的会话，不因版本变化清空账号、设备标识、设置或历史记录。
  已有会话的旧版用户直接进入首页，无须重新完成年级引导。
- 临时解密/Keystore 读取失败保留原密文，搜题正文中的登录提醒也不会删除会话。
- 重新登录完成且凭据保存成功后才替换内存会话；取消或保存失败保留原账号。
- 会话变更与“仅清除该请求所用账号”共用同步锁，旧请求不能删除新登录的账号，
  旧资料请求也不能覆盖新账号。
- 用户主动退出或服务端明确返回当前凭据失效时，仍按原有规则清除对应会话。

登录成功以 Activity 结果码确认，并刷新原任务的 KDUSS/UID 快照和 generation；
保留上传图片、整页/框选模式与题块关联参数，避免恢复后的答案因旧快照而被丢弃。
旧版历史里已有的登录提醒同样显示登录按钮，不删除历史文件。

本轮验证限于代码检查、纯本地单元回归、Android Lint、编译打包及安装包签名比对。
